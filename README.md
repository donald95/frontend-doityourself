# Vue 3 + TypeScript + Vite

## Versions of the frontend tools

1. Node JS v18.10.0.
2. npm v8.19.2
3. Vite v2
4. Vue v3

## Steps to run

1. git clone git@github.com:donald95/frontend-doityourself.git
2. cd frontend-doityourself/
3. npm install
4. npm run build
5. npm run preview
6. ➜ Exposed Local Link: http://localhost:4173/
